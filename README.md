# Danatela — PWA-конструктор торта

## Что внутри

Статическая PWA-версия для GitHub Pages. В браузере клиента работают четыре шага конструктора: вес и форма, начинка, дизайн, детали и способ получения. Стоимость рассчитывается в реальном времени по формуле `вес × (основа + начинка за кг) + дизайн + форма + дополнения + доставка`.

В кабинете кондитера есть вкладки «Цены», «Начинки» и «Заявки». На вкладке «Начинки» можно добавить вкус, изменить название, описание, аллергены, доплату за килограмм и цвета карточки, а также удалить позицию. Удаление выбранной начинки автоматически выбирает другую. Последнюю начинку удалить нельзя. Уже созданная заявка хранит снимок названия и цены, поэтому удаление каталожной позиции не меняет старые тексты.

Начинки, цены и заявки намеренно хранятся только в памяти текущей вкладки. После обновления страницы или перезапуска снова загружаются тестовые данные. Это сделано по вашему требованию «пока без сохранения». Экспорт каталога JSON доступен в разделе «Цены»; он содержит каталог и цены, но не заявки.

VK пока подключён визуально: приложение формирует текст заявки, позволяет скопировать или скачать его и открыть страницу `https://vk.ru/danatela_cake`. Автоматической отправки в VK, токена, оплаты, общей базы и защищённой админки нет.

## PWA

В проекте есть `manifest.webmanifest`, `sw.js`, `pwa.js`, `build.py`, SVG-логотип и GitHub Actions. Service worker кэширует только публичные файлы приложения: HTML, JS, manifest и иконки. Заявки и каталог в кэш не попадают. Обновление новой версии ожидает подтверждения пользователя, чтобы не сбрасывать текущую сессию неожиданно.

На iPhone открывайте опубликованный HTTPS-адрес в Safari, нажмите «Поделиться» → «На экран „Домой“». В приложении есть кнопка с инструкцией. Установка из файла `file://` невозможна. Для GitHub Pages используйте публикацию через встроенный workflow: он поддерживает URL проекта с подпапкой, например `https://username.github.io/repository/`.

## Публикация через GitHub

Создайте новый пустой репозиторий и загрузите содержимое этой папки. Не загружайте JSON с реальными заявками и фотографии клиентов. Workflow `.github/workflows/pages.yml` сам соберёт PNG-иконки, проверит PWA в Chromium и опубликует папку `dist` на GitHub Pages.

В репозитории откройте Settings → Pages и в разделе Build and deployment выберите Source: GitHub Actions. После завершения workflow адрес будет показан в его окружении `github-pages`. Если repository называется не так, как сайт, ничего менять в коде не нужно: сборка использует относительные пути.

Секреты VK в репозиторий не добавляйте. В этой версии VK API не используется.

## Локальная сборка

Нужны Python 3.10+, Node.js 20+ и npm. В этой среде запуск shell не состоялся из-за отключённой виртуализации, поэтому ниже приведены команды для вашего компьютера.

```bash
python3 build.py
npm install
npx playwright install chromium
npm test
python3 -m http.server 8080 --directory dist
```

После запуска откройте `http://127.0.0.1:8080/`. Сайт можно проверить на телефоне только через HTTPS или через локальный HTTPS-сервер; обычный HTTP на другом устройстве не даст полноценную установку PWA.

`npm test` проверяет запуск, встроенные формулы, мобильную ширину, динамический каталог, добавление и удаление начинок, защиту последней позиции, старую заявку после удаления начинки, HTML-экранирование, manifest, PNG-иконки, работу из подпапки GitHub Pages, офлайн-перезагрузку и отсутствие лишних файлов в service worker cache. Он создаёт `screenshots/`, которые workflow сохраняет как artifact. `build.py` создаёт `dist/` и архив `danatela-pwa-site.zip`.

## Ограничения перед настоящим запуском

Админка сейчас открыта клиентам и не защищена. Изменения каталога в одном браузере не видны вам на другом устройстве. Заявки не сохраняются. Для production понадобятся серверная база данных, авторизация администратора, серверный расчёт цены, обработка персональных данных, хранение референсов, настоящая отправка VK через секретный токен, политика конфиденциальности и проверка доступности дат.

Все текущие названия, составы, аллергены и цены демонстрационные. Аллергены обязательно сверить с реальными рецептами до публикации для клиентов.
