# Актуальная версия

Проект обновлён до PWA с управлением начинками. Актуальная инструкция находится в `README.md`.

Для установки на iPhone нужна опубликованная HTTPS-версия, а не отдельный HTML-файл. Сборка `python build.py` создаёт каталог `dist` с HTML, service worker, manifest и PNG-иконками. Все необходимые исходники и workflow входят в выданные файлы.

Добавление, редактирование и удаление начинок работает в текущей сессии без автоматического сохранения. После обновления приложения изменения сбрасываются. VK остаётся визуальным: скопируйте подготовленный текст и отправьте вручную.
